Pengelola: CIHUY. Kontak: 11231017@student.itk.ac.id. Lengkapi sebelum dipublikasikan.

Untuk menghapus akun melalui aplikasi: buka Profil > Pengaturan > Hapus akun dan konfirmasikan.

Jika aplikasi tidak terpasang, kirim permintaan penghapusan akun CIHUY ke 11231017@student.itk.ac.id dengan subjek "Permintaan hapus akun CIHUY". Kirim dari alamat email yang digunakan pada akun CIHUY agar kepemilikan akun dapat diperiksa. Jangan sertakan password, kode OTP login, atau token sesi. [LENGKAPI prosedur verifikasi kepemilikan sebelum permintaan diproses.]

Data yang dihapus mencakup akun autentikasi, profil, dan foto profil pada layanan aplikasi. Catatan konsumsi, craving, serta target versi ini tersimpan lokal pada perangkat; penghapusan via web tidak dapat menghapus berkas lokal dari jauh. Hapus data aplikasi pada perangkat terkait untuk membersihkannya. Salinan ekspor di luar aplikasi perlu dihapus sendiri.
